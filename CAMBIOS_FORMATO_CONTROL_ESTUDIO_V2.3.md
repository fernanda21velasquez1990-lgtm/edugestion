# EduGestión V2.3 — Formato Control de Estudio

- El formato para Control de Estudio ahora muestra solo: nombre de la evaluación, cómo se evaluará, puntaje y fecha.
- Se trabaja por año/grado, no por una sección aislada.
- Las secciones del mismo año se agrupan en un solo plan.
- Para una misma evaluación aplicada en fechas distintas entre secciones, la fecha se muestra automáticamente como Desde / Hasta.
- La vista previa sigue siendo editable antes de imprimir.
- La salida mantiene encabezado institucional y 2 hojas tamaño carta horizontal.

# EduGestión V6.3 · Asistencia avanzada

Incluye:
- Tarjeta independiente por cada sección/clase del día.
- Cada tarjeta muestra Presentes, Ausentes, Tardanzas, Justificadas y porcentaje del día.
- Alertas automáticas desde 3 ausencias o 3 tardanzas.
- Ranking de alumnos con mayor inasistencia.
- Historial mensual visual.
- Comparación acumulada entre secciones.
- Botón Cerrar asistencia del día y opción para reabrirla.
- Bloqueo de cambios accidentales mientras la asistencia está cerrada.
- Auditoría de correcciones usando los registros existentes del servidor.
- Informe imprimible por sección.
- Informe individual imprimible por alumno.
- Exportación compatible con Excel mediante CSV.
- Mantiene historial, recuperación, progreso y jornadas pendientes de V6.2.

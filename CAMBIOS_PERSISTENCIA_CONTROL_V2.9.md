# EduGestión V2.9 — persistencia y cierre de 1er lapso

- El Panel por lapso recuerda el año, lapso y filtro seleccionados.
- Si el navegador no tiene asignaciones guardadas para 1er Año, se recuperan automáticamente los 6 temas definidos para el 1er Lapso.
- El Formato Control de Estudio usa siempre los 6 temas curriculares correctos de 1er Año / 1er Momento, aunque el almacenamiento local esté vacío.
- Las 3 superclases de gimnasio se integran dentro de Actividades de los temas correspondientes y no aparecen como temas nuevos.
- Tema Indispensable, Tema Generador, Referente Teórico-Práctico, Potencialidades, Actividades e Intencionalidades Pedagógicas quedan autocompletados; Énfasis curricular se marca automáticamente.
- El formato sigue dividido en 2 hojas tamaño carta horizontal (3 temas por hoja).
- El Plan de Evaluación para alumnos también recupera automáticamente los mismos 6 temas del 1er Lapso si faltan asignaciones locales.

Importante: el almacenamiento del navegador pertenece al dominio. Para conservar datos editados manualmente, usar siempre la URL oficial estable de producción y no una URL temporal de Preview/Deployment de Vercel.

# EduGestión V4.0 - Reglamento Docente

- Nueva pestaña **Reglamento docente** disponible para los perfiles de Educación Física, Ciencias Naturales y Biología.
- Se integra el PDF oficial del **Reglamento del Ejercicio de la Profesión Docente (Decreto N.° 1.011, 4 de octubre de 2000)**.
- Botones para abrir el PDF completo y descargarlo.
- Visor PDF dentro de EduGestión.
- Accesos rápidos a disposiciones generales, deberes, derechos, carrera/escalafón, dedicación/carga horaria y evaluación/clasificación.
- El módulo es solo de consulta y no altera planificaciones ni datos docentes.

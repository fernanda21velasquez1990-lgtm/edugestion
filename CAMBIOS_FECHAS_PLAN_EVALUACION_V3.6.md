# V3.6 — Fechas reales del Plan de Evaluación

- Las fechas ya no quedan a criterio de Gemini.
- EduGestión recalcula cada evaluación con el horario real cargado de cada sección.
- Para una misma actividad en secciones A y B:
  - **Desde** = primera fecha real de aplicación.
  - **Hasta** = última fecha real de aplicación.
- Respeta el espacio real: Aula, Cancha o Gimnasio.
- Las 3 superclases usan sus semanas reales de gimnasio.
- Se habilitaron las superclases también para 3.er Año.
- Se agregó el botón **Recalcular fechas según horario** para corregir un plan ya generado sin volver a llamar a Gemini.
- Las actividades curriculares se distribuyen progresivamente a lo largo del lapso y no se colocan todas en lunes.

# EduGestión V3.7 · Cuadernillo Ciencias Naturales

- Se incorpora el documento `Ciencias Naturales. Propuestas de contenidos para la enseñanza y aprendizajes esperados` (MPPE, septiembre 2025).
- Nueva pestaña **Cuadernillo Ciencias Naturales** visible para docentes cuyo perfil tenga el área **Ciencias Naturales**.
- Se incluyen los contenidos integrados de **1er Año** y **2do Año**, organizados en los seis componentes del documento:
  - Seres vivos
  - Investigando en las ciencias
  - El ambiente y sus interacciones
  - Energía - materia
  - El universo
  - Ciencia, tecnología y sociedad
- Cada contenido incluye: componente, contenidos esenciales, aprendizajes esperados, referentes y página del documento.
- Botones: Ver base curricular, Seleccionar tema, Planificar con IA y Abrir PDF original.
- El **Panel por lapso** reutiliza estos contenidos cuando el profesor activo es de Ciencias Naturales.
- La planificación semanal y el Formato Control pueden leer los temas que el profesor distribuya por lapso.
- Las superclases de gimnasio quedan desactivadas automáticamente para docentes que no sean de Educación Física.
- A partir de 3er Año el documento separa Biología, Química, Física y Ciencias de la Tierra; por eso esta primera integración de "Ciencias Naturales" muestra 1er y 2do Año. Las áreas específicas pueden incorporarse como módulos separados.

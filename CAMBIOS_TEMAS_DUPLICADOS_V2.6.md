# EduGestión V2.6 — Corrección de temas repetidos

- Cada contenido del cuadernillo se identifica ahora por año + título + página + descriptor curricular.
- Quitar un tema del lapso ya no quita otros contenidos que tengan el mismo nombre en páginas distintas.
- La asignación independiente se respeta en Panel por lapso, Plan anual, Planificación semanal, Formato Control de Estudio y Plan de Evaluación para alumnos.
- Se mantiene compatibilidad con asignaciones antiguas cuando el título es único.
- Para títulos duplicados, las asignaciones antiguas ambiguas no se reutilizan automáticamente: deben asignarse una sola vez con la nueva versión.
